# 🐻 熊出没森林探险 (Boonie Bears Keyboard Smasher)

一款专为 1-3 岁婴幼儿设计的桌面级全球键盘随心按游戏（Keyboard Smasher）。让宝宝尽情发挥“破坏力”的同时，保障家长的电脑环境绝对安全。

## 💡 设计理念

对于 2 岁左右处于探索期的小朋友，键盘对他们有着莫大的吸引力：他们喜欢毫无章法地用力拍打键盘。然而，市面上的普通儿童网页游戏存在以下痛点：
1. **防切出能力薄弱**：小孩极易通过乱按触发 `ESC`, `Alt+Tab`, `Command+Space` 或 `F11` 等系统快捷键退出全屏，导致误删家长重要文件或打断工作。
2. **缺乏即时狂野的反馈**：只有点击特定按钮才有反馈，不能满足宝宝“按哪亮哪”的即时快感。

为了彻底解决这一问题，本项目**放弃了传统的纯网页方案，而是通过 Electron 原生应用层+Kiosk（信息亭）模式打造了完美的“防沉迷锁屏体验”**。

在运行本游戏后，您的屏幕将变成一个完全接管所有系统输入的“黑盒”。小朋友的任何按键动作（包括系统级特殊键位），都会被转化为屏幕上的粒子特效、屏幕震动和有趣的音效。

## 🎮 游戏特色

- 🔒 **无懈可击的安全锁（Kiosk Mode）**：
  开启强制全屏、无边框、最高层级置顶。在底层通过 `globalShortcut` 吞没所有试图切出应用的系统按键（如 `Command+Tab`, `Ctrl+Alt+Del`, 双击 Command），彻底接管电脑系统快捷键。
- 🐻 **丰富的《熊出没》3D主题元素**：
  融合了高质量 3D 渲染的森林背景，更有按压触发的熊大、熊二、光头强动态翻转飞入动画。
- 🔊 **基于 Web Audio API 的程序化音效**：
  告别笨重的外部音频文件！完全通过浏览器内置数学模型实时合成各类弹跳音、叮咚声、滑稽下降音效，零延迟响应。
- ✨ **满屏视听特效轰炸**：
  随机掉落的巨型 Emoji（🪵、🪓、🍯、蝴蝶飞舞等），配合物理级的多幅屏幕震动（Shake）与雷电全屏闪存反馈。
- 🚪 **隐秘的家长专属出口**：
  需要由家长长按特定按键超过3秒才会激活退出，婴儿无法仅仅通过随机乱按达成闭合条件。

## 🚀 立即开始

### 方式一：直接下载安装客户端 (推荐)
前往项目的 [Release 页面](https://github.com/orime/children-games-boonie-bears/releases) 下载最新版本的打包好的安装程序（支持 macOS `.dmg` 或 Windows `.exe` 等）。
解压或安装之后，双击应用图标即可直接启动运行。不需要配置任何开发环境！

### 方式二：通过源码运行

如果您希望二次开发或本地运行源码，请确保您的电脑已安装 [Node.js](https://nodejs.org/) (附带 npm)。

```bash
# 1. 克隆代码库
git clone https://github.com/orime/children-games-boonie-bears.git
cd children-games-boonie-bears

# 2. 安装依赖
npm install

# 3. 启动游戏
npm start
```
> **注意**：启动后应用将立刻进入全屏并锁死屏幕。在游玩结束前，您在此桌面上的其它工作将被完全遮挡。

## 🔑 退出指南（家长必读）

请熟记以下全局退出密码。由于它同时接管了所有系统级退出的方案（不再响应 `Cmd+Q` 或 `Alt+F4`），这是唯一能正常退出游戏的手段。

**家长退出密码：**
长按 `Command + Shift + W` (Windows 为 `Ctrl + Shift + W`) **持续 3 秒钟以上**。

触发时，屏幕上会出现一个红色的进度条，进度条走满后窗口将安全销毁。
*(备用手段：方向键依次输入：⬆️ ⬆️ ⬇️ ⬇️ ⬅️ ➡️ ⬅️ ➡️)*

## 🛠 技术栈

- **前端层 (UI/特效)**: Vanilla HTML5 / JS / CSS (CSS3 原生 Animation, Canvas)
- **音效层**: JavaScript Web Audio API `OscillatorNode` / `BiquadFilterNode`
- **容器层 (桌面包装与权限劫持)**: Electron (Kiosk / globalShortcut APIs)
- **美术资产**: AI 人工智能生成的透明通道 Sprite 游戏精灵图。
